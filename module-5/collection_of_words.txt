In this module we learned about sets and maps. A set does not allow duplicate values,
so if I add the word "set" ten times, the set still holds only one copy of it.
A HashSet does not keep any order, a LinkedHashSet keeps the insertion order,
and a TreeSet keeps every word sorted in ascending order.
A map stores a key and a value. The key must be unique, but the value can repeat.
